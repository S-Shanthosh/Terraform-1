# Terraform CloudShell Setup

## One-Command Bootstrap (fresh AWS account)

```bash
# 1. Clone the repo
git clone https://github.com/S-Shanthosh/Terraform-1.git ~/terraform-demo
cd ~/terraform-demo

# 2. Run bootstrap (only once per account)
chmod +x setup/bootstrap.sh
./setup/bootstrap.sh
```

That's it. You'll be asked for a bucket name — everything else is automatic.

---

## Every new CloudShell session (after first time)

```bash
source ~/terraform-demo/setup/tf-start.sh
```

## Before exiting CloudShell

```bash
~/terraform-demo/setup/tf-save.sh
```

---

## Folder Structure

```
Terraform/
├── setup/
│   ├── bootstrap.sh     ← Run ONCE per new AWS account
│   ├── tf-start.sh      ← Run at start of every session
│   └── tf-save.sh       ← Run before exiting
├── bootstrap/
│   └── main.tf          ← Reference only (bootstrap.sh uses AWS CLI instead)
└── Infra/
    ├── backend.tf        ← Auto-generated by bootstrap.sh
    ├── main.tf
    ├── provider.tf
    ├── variables.tf
    ├── outputs.tf
    ├── terraform.tfvars
    ├── environments/
    │   ├── dev/dev.tfvars
    │   └── prod/prod.tfvars
    └── modules/
        ├── vpc/
        ├── ec2/
        ├── s3/
        └── lambda/
```
