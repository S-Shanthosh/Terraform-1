## ⚡ Quickstart

```bash
# Clone anywhere — path doesn't matter
git clone https://github.com/S-Shanthosh/Terraform-1.git workspace

# One command does everything
chmod +x ~/workspace/setup/bootstrap.sh && ~/workspace/setup/bootstrap.sh
```

> 💬 **One question asked.** One answer needed — your state bucket name. Everything else: fully automatic.

## 🧠 What `bootstrap.sh` Does

| # | Step | Detail |
|---|------|--------|
| 1 | 📍 **Auto-detect repo path** | Works regardless of clone folder name |
| 2 | ⬇️ **Install Terraform 1.7.5** | Skips silently if already present |
| 3 | 🔧 **Configure `.bashrc`** | Sentinel-guarded — safe to run multiple times |
| 4 | 🪣 **Create S3 state bucket** | Versioned · Encrypted · Public access blocked |
| 5 | 🔒 **Create DynamoDB lock table** | Prevents concurrent state corruption |
| 6 | 🔑 **Generate SSH key pair** | RSA 4096-bit · Auto-backed up to S3 |
| 7 | 📝 **Write `backend.tf`** | Dynamically wired to your bucket |
| 8 | 🔐 **Set script permissions** | No more permission denied errors |
| 9 | 🚀 **Run `terraform init`** | Downloads and caches providers |
| 10 | 💾 **Save session to S3** | Next login restores in seconds |

## 💣 Auto-Destroy Pipeline

Protects against forgotten resources and runaway AWS bills. Runs entirely serverless.

```
  Every 1 Hour
       │
       ▼
  ┌─────────────────┐
  │  EventBridge    │  Scheduled rule — triggers every hour
  └────────┬────────┘
           │
           ▼
  ┌─────────────────┐
  │    Lambda       │  Checks tfstate LastModified timestamp in S3
  │  Python 3.12    │  If age > 1 hour → trigger destroy
  └────────┬────────┘  If age ≤ 1 hour → skip (within TTL)
           │
           ▼
  ┌─────────────────┐
  │   CodeBuild     │  Installs Terraform · writes backend.tf
  │  buildspec.yml  │  terraform destroy -auto-approve (dev + prod)
  └─────────────────┘
```

> 🧠 **Smart TTL**: Lambda reads the actual `LastModified` timestamp of `terraform.tfstate` in S3. It only destroys if resources have been live for more than 1 hour — not just if 1 hour has passed since the pipeline last ran.

### Setup Auto-Destroy

```bash
bash ~/workspace/setup/resource-cleanup.sh
```

### Manual Controls

```bash
# Test Lambda decision (check only, no destroy)
aws lambda invoke \
  --function-name terraform-state-checker \
  --region ap-south-1 \
  /tmp/out.json && cat /tmp/out.json

# Force immediate destroy
aws codebuild start-build \
  --project-name terraform-auto-destroy \
  --region ap-south-1
```

## 🔁 Idempotency — Safe for Repeat Runs

| Step | Protection |
|------|-----------|
| Terraform install | Version check before download |
| `.bashrc` config | `# __TF_BOOTSTRAP_DONE__` sentinel |
| S3 bucket | `head-bucket` existence check |
| DynamoDB table | `describe-table` existence check |
| SSH key | `[ -f "$KEY_PATH" ]` file check |
| Lambda / CodeBuild | `get-function` / `batch-get-projects` check |
| EventBridge rule | `put-rule` is idempotent by design |

## 🧹 Full Account Teardown

```bash
# 1. Destroy all Terraform-managed resources
cd ~/workspace/Infra && terraform destroy -auto-approve -var-file=environments/dev/dev.tfvars

# 2. Delete state bucket
aws s3 rm s3://<your-bucket> --recursive
aws s3api delete-bucket --bucket <your-bucket> --region ap-south-1

# 3. Delete DynamoDB lock table
aws dynamodb delete-table --table-name <your-bucket>-locks --region ap-south-1

# 4. Delete auto-destroy pipeline
aws lambda delete-function --function-name terraform-state-checker --region ap-south-1
aws codebuild delete-project --name terraform-auto-destroy --region ap-south-1
aws events delete-rule --name terraform-auto-destroy-hourly --region ap-south-1

# 5. Clean local environment
rm -rf ~/workspace ~/bin/terraform /tmp/.terraform
rm -f ~/.ssh/shanthosh-key ~/.ssh/shanthosh-key.pub

# 6. Clean .bashrc
sed -i '/# __TF_BOOTSTRAP_DONE__/,$ d' ~/.bashrc
```

## ⚠️ Important Notes

| | |
|---|---|
| 🔐 **IAM** | Terraform inherits your CloudShell role. Check with `aws sts get-caller-identity` |
| 🌏 **Region** | Hardcoded to `ap-south-1`. Change `REGION` in `bootstrap.sh` if needed |
| 💰 **Cost guard** | Auto-destroy pipeline triggers after 1 hour of resource uptime |
| 🔄 **Multi-account** | Run `bootstrap.sh` once per AWS account — each gets its own state bucket |
| 👥 **Teams** | Use module ownership + GitHub PRs for collaboration. One state, divided responsibility |
